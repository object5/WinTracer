# WinTracer

[English](README.md) | Русский

Утилита, чтобы следить за Windows и не переустанавливать её каждые полгода. Смотрит, куда делось место на дисках, что висит в автозагрузке, чистит мусор и битые записи в реестре, плюс пачка твиков.

WPF на .NET 10, интерфейс сделан на [WPF-UI](https://github.com/lepoco/wpfui).

## Что умеет

### Место на дисках
- Сканирует диск или любую папку, показывает дерево папок по размеру и содержимое выбранной папки.
- Видно и обычный размер, и сколько реально занято на диске (с учётом сжатия и файлов OneDrive).
- ПКМ по файлу или папке: открыть, показать в Проводнике, скопировать путь, переместить, удалить в корзину или насовсем.
- Del — в корзину, Shift+Del — насовсем, Backspace — на уровень вверх.
- Удалить или переместить C:\Windows, Program Files, профиль и прочие системные вещи не даст.
- C: на ~1 млн файлов сканируется секунд за 7–10.

### Автозагрузка
- Собирает в одном месте: Run в реестре, папки «Автозагрузка», задачи планировщика (при входе/загрузке) и сторонние службы.
- Отключает так же, как Диспетчер задач — запись остаётся, обратно включается тем же переключателем.
- Службы при отключении переводятся в ручной запуск, а не выключаются совсем.
- Битые записи (файла нет) можно удалить, перед этим сохраняется .reg или копия ярлыка.

### Очистка
- Temp, кэш Windows Update, оптимизация доставки, дампы и отчёты об ошибках, кэш эскизов, логи, корзина, WinSxS через DISM.
- Кэш браузеров (Chrome, Edge, Яндекс, Firefox, Opera, Brave) — куки, история и пароли не трогаются.
- Discord, Steam, VS Code, кэши NuGet/npm/pip/uv.
- Нейросети: Claude Code, Claude Desktop, Codex, OpenCode, Antigravity. Чистятся кэши, логи, телеметрия, скачанные обновления и старые версии. Авторизация, настройки, память и история не трогаются. Историю старых сессий можно удалить отдельно, по умолчанию выключено.
- Перед очисткой показывает, сколько освободится. Занятые файлы пропускает.

### Реестр
- Ищет только то, что точно мусор — записи, которые указывают на несуществующие файлы и папки:
  - программы в «Установленных приложениях», от которых ничего не осталось;
  - App Paths и «Открыть с помощью» на удалённые exe;
  - правила брандмауэра для удалённых программ;
  - общие DLL и папки установщика, которых нет;
  - MUICache.
- Перед удалением всё сохраняется в один .reg — двойной клик и всё вернулось.
- Можно заодно создать точку восстановления (нужны права админа).

### Твики
Основа — список из [object5/Tweaker](https://github.com/object5/Tweaker), но каждый твик видит своё текущее состояние и откатывается обратно.

- Конфиденциальность: телеметрия, рекламный ID, сбор ввода, журнал действий, Copilot, Recall, веб-поиск в «Пуске», Spotlight.
- Интерфейс: реклама и рекомендации, виджеты, «Этот компьютер» в Проводнике, расширения файлов, скрытые файлы, «Завершить задачу» на панели задач.
- Производительность: задержка автозапуска, игровой режим, Game DVR, HAGS, схема Ultimate Performance, power throttling, network throttling, ускорение мыши, dynamic tick.
- Обновления: отключение P2P-раздачи.
- Удаление встроенных приложений (Новости, Погода, Xbox и т.д.) для текущего пользователя.

## Язык

Интерфейс на русском и английском. По умолчанию берётся язык Windows, поменять можно в настройках (нужен перезапуск).

## Права администратора

Запускается без них. Для системных папок, HKLM, служб и части твиков нужен перезапуск от админа — кнопка есть в шапке почти каждого раздела и в настройках.

## Резервные копии

`%LOCALAPPDATA%\WinTracer\Backups` — .reg-файлы и ярлыки, удалённые из реестра и автозагрузки.
`%LOCALAPPDATA%\WinTracer\tweaks-backup.json` — старые значения, которые были до применения твиков.

## Сборка

Нужен .NET 10 SDK.

```
dotnet build SpaceTracer/WinTracer.csproj -c Release
```

Тесты:

```
dotnet test WinTracer.sln
```

На GitHub сборка идёт сама (`.github/workflows/build.yml`): на каждый push и PR собирается проект, гоняются тесты, готовый exe лежит в артефактах. Если запушить тег `v*` (например `v0.2.0`), zip с exe прикрепится к релизу.

Можно сразу открыть нужный раздел: `WinTracer.exe --page=cleanup` (ещё `startup`, `registry`, `tweaks`, `settings`).

## Чего пока нет

- Нет привязки папок к программам и поиска брошенных папок.
- Жёсткие ссылки считаются по каждой копии, поэтому C:\Windows в анализе выглядит больше, чем есть.
- Нет быстрого сканирования через MFT.
